# OceanData

A product-grade instrument for verifying and extracting real oceanographic observations from authoritative providers.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

The initial app shell includes the OceanData token system and the persistent query readout bar. Provider readings remain empty until verified backend connectors are integrated.

## Evidence

Provider feasibility records and reproducible live-request results are maintained under `docs/evidence/`.
